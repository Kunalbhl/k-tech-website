Data Deletion

Community Manager · a product of K. Tech Services · Last updated 16 November 2026

You can ask for the data Community Manager holds about you to be deleted at any time.

Members and applicants

  1. Ask the server's staff to delete your application or records from the dashboard, or
  2. email support@chaloone.com with your Discord user ID and the server name. We confirm and delete within 30 days.

Server admins

  1. Delete records from the dashboard, or remove the bot from your server.
  2. email support@chaloone.com with the server ID to delete all of the server's data. We confirm and delete within 30 days.

Dashboard sign-in

Discord → User Settings → Authorized Apps → remove Community Manager. This ends dashboard access; ask us if you also want your profile data deleted.
