Privacy Policy

Community Manager · a product of K. Tech Services · Last updated 16 November 2026

Community Manager is a Discord bot and web dashboard that helps communities run recruitment and day-to-day community work: applications, interviews, recruiter codes and rewards, onboarding, roles, events, reminders, server stats and growth reports. It is built and operated by K. Tech Services, India ("we", "us"). This policy explains what we collect, why, and your choices.

In short: we only use data needed to run the features a server turns on. We never see your Discord password, never sell your data and never use it for advertising.

1. Information we collect

SourceWhatWhy
Discord login (dashboard)Discord user ID, username, avatar, and the servers you belong to or manage (identify, guilds)To sign you in and show the servers you can manage
Servers using the botServer ID and name, channels, roles, member IDs and usernames, join and leave times, and the settings admins chooseTo run onboarding, roles, stats counters, growth reports and other features
Applications and interviewsAnswers you submit, how you found the server, recruiter code used, application status, interview times, reviewer notes and decisionsTo process applications and let staff review them
Recruiter codes and rewardsCodes, who joined with them, points, rewards claimed and approvalsTo credit recruiters and run reward programmes
Messages the bot handlesMessages sent to the bot or in channels the bot manages for a feature (for example application rooms, quizzes or reminders)Only to run that feature; we do not read or store general server chat
TechnicalLogs, errors and basic request data (IP address, browser), session cookieTo keep the service secure and working

If a server turns on optional AI-assisted features, the relevant text (for example an application answer) may be processed by Google's Gemini API only to produce that result.

2. What we never do

  • We never see or store your Discord password.
  • We never sell your data, share it with advertisers, or use it to train AI models.
  • We never act in servers beyond the permissions admins grant the bot.

3. How we use information

Only to provide Community Manager's features to the servers that use it, show information to that server's staff in the dashboard, send the messages and DMs those features need, prevent abuse and answer support requests.

4. Who can see it

Server data is visible to that server's staff according to the roles and permissions its admins set. We share data only with the services needed to run Community Manager: Discord, and our hosting and database providers (Google Cloud, Cloudflare, Supabase, Oracle Cloud), which process it on our behalf. We may disclose information if required by law.

5. Storage and security

Data is stored in a managed PostgreSQL database. All traffic uses HTTPS, secrets are stored encrypted, and access is limited to the service and its operator.

6. Retention

We keep a server's data while the bot is in that server. Server admins can delete applications and other records from the dashboard. When the bot is removed or you ask us, we delete the server's data within 30 days. Security logs are kept for up to 90 days.

7. Your choices and rights

  • Members: ask the server's staff, or us, to see, correct or delete your applications and records.
  • Admins: remove the bot from your server at any time and ask us to delete the server's data.
  • Dashboard access: Discord → User Settings → Authorized Apps → remove Community Manager.

We process personal data in line with India's Digital Personal Data Protection Act, 2023 and, where applicable, other privacy laws such as the GDPR. We respond to requests within 30 days. See Data Deletion.

8. Children

Community Manager follows Discord's age requirements and is not intended for anyone under 13 (or the minimum age in their country).

9. Changes

We will update this page if our practices change and show the new date at the top.
